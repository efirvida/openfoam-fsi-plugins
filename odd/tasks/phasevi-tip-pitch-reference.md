# Phase VI tip-pitch reference A/B (towards Model Definition v1.3)
Root-cause audit 2026-10-22 found the blade mounted at twist + 3 deg while NREL defines the 3 deg pitch at the tip chord
(twist is zero at 75 % span, -1.815 deg at the tip). This feature adds the tip reference as a switch, runs a 2x2 (pitch reference x drag polar) on Sequence S, and records the evidence for a v1.3 decision.

- S4 (repository rules): v1.2 stays reproducible (the switch defaults to the v1.2 rendering, byte-identical); a variant != v1.2 is never of record; Slurm `--ntasks` only; no rebuild of `libturbinesFoam` (no C++ change: the installed lib, mtime 2026-10-12, is the one every v1.2 baseline used).
- S5 (physical definition, NREL/TP-500-29955): PDF p.20 "blade pitch is defined as the angle between the blade tip chord line and the plane of the turbine disk"; Table A-1 note 2 "Twist convention is positive towards feather. Values listed are relative to zero twist at the 3.772-m station [75% span on a 5.029-m blade]." Tip reference mounting: `-(twist - twist_tip + pitch_deg)` with `twist_tip = -1.815` (table row r = 5.029 m); tip mounting becomes -3.0 deg.
